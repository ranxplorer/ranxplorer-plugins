# Ranxplorer Plugins

[English](#english) | [Français](#français)

---

## English

The Ranxplorer marketplace provides the `Ranxplorer MCP` plugin.

### Installation

Add the Ranxplorer marketplace to Claude Code:

  ```bash
  claude plugin marketplace add ranxplorer/ranxplorer-plugins
  ```

Add the Ranxplorer marketplace to Codex CLI:

  ```bash
  codex plugin marketplace add ranxplorer/ranxplorer-plugins
  ```

### Available plugins

- [Ranxplorer MCP](https://github.com/ranxplorer/ranxplorer-plugins/tree/main/plugins/ranxplorer-mcp)
